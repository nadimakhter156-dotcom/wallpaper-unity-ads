# Unity Ads Demo (Wallpaper)
Native Android Kotlin + Jetpack Compose app featuring Unity Ads 4.21.0 integration.

- Package Name: com.wallpaper
- Application ID: com.aizoid.unityadsdemo
- Unity Game ID: 800105834
- minSdk: 24, targetSdk: 34

## How to build
1. Open this folder in Android Studio (Jellyfish, Koala, Ladybug, or Meerkat).
2. Allow Gradle to sync.
3. Select 'Build > Build Bundle(s) / APK(s) > Build APK(s)'.
4. Transfer app-debug.apk to your phone or run via USB Debugging.
